#### 1. 关于DDS

**DDS（Direct Digital Synthesis，直接数字频率合成）** 是一种通过**全数字技术生成任意波形和频率**的信号生成方案。其核心原理如下：

```Mermaid
graph LR
    A[参考时钟] --> B[相位累加器]
    B --> C[相位-幅度转换]
    C --> D[波形查找表]
    D --> E[DAC]
    E --> F[低通滤波器]
    F --> G[模拟信号输出]
```

| **特性**       | **实现方式**                       | **优势**         |
| -------------- | ---------------------------------- | ---------------- |
| **频率分辨率** | Δf = f<sub>clk</sub>/2<sup>N</sup> | 可达0.01Hz级精度 |
| **相位连续性** | 相位寄存器累积                     | 扫频无断点       |
| **频谱纯度**   | 全数字合成+低通滤波                | SFDR > 70dB      |
| **响应速度**   | 单时钟周期切换                     | 频率切换<10ns    |

> **物理本质**：DDS = 数字信号处理器件（FPGA/ASIC） + 高速DAC + 低通滤波器

#### 2. 关于ADS9833

AD9833是**集成DAC的完整DDS系统**

```Mermaid
graph TD
    AD9833 -->|包含功能模块| B[相位累加器]
    AD9833 -->|包含功能模块| C[正弦/三角查找表]
    AD9833 -->|包含功能模块| D[10位高速DAC]
    AD9833 -->|输出特性| E[电流型模拟输出]
```

这个9833自带一个stm32的芯片，9833芯片直接被这个stm32控制，编程时直接对模块的stm32编程，使用串口通信，主控制器通过串口向模块的发送信息，模块自带的stm32收到信息，进行处理，进而控制DDS输出波形。 有12位相位寄存器，控制相位。

可以生成三种波形：

```c
#define TRI_WAVE 	0  		//输出三角波
#define SIN_WAVE 	1		//输出正弦波
#define SQU_WAVE 	2		//输出方波
```

具体怎么连可以看资料包中的pcb，串口连接在背面，st_link在侧面

驱动文件是9833.c.h，主要是两个函数（单通道配置、双通道配置）：

```c
void AD9833_WaveSeting(double frequence,unsigned int frequence_SFR,unsigned int WaveMode,unsigned int Phase, unsigned char channel );

//参数
void AD9833_WaveSeting(
    double frequence,         // 输出频率 (0.1Hz-12MHz)
    unsigned int frequence_SFR, // 频率寄存器选择 (0=寄存器0, 1=寄存器1)
    unsigned int WaveMode,    // 波形类型 (TRI_WAVE/SIN_WAVE/SQU_WAVE)
    unsigned int Phase,       // 相位值 (0-4095对应0-360°)
    unsigned char channel     // 通道选择 (0或1)
);


void AD9833_WaveSeting_Double(double Freq,unsigned int Freq_SFR,unsigned int WaveMode,unsigned int Phase);

//参数
void AD9833_WaveSeting_Double(
    double Freq,              // 输出频率 (两个通道相同)
    unsigned int Freq_SFR,    // 频率寄存器选择
    unsigned int WaveMode,    // 波形类型
    unsigned int Phase        // 通道1相位值
);

void AD9833_Write(unsigned int TxData, unsigned char channel)
```

- 单通道函数用于独立配置一个通道的所有参数（频率、波形、相位）。
- 双通道函数用于同时配置两个通道的频率和波形，但仅设置通道1的相位（通道0相位不变）。因此，如果需要对两个通道都设置相位，需要额外操作。

#### 3. 案例

使用`AD9833_WaveSeting_Double`函数实现：

```c
// 计算30°相位对应的相位寄存器值
uint16_t phase_value = (uint16_t)(30.0 / 360.0 * 4096);  // = 341

// 生成1kHz正弦波，通道1相位偏移30°
AD9833_WaveSeting_Double(1000.0, 0, SIN_WAVE, phase_value);
```
